# SenseAir S8 Monitor для Home Assistant

Локальная интеграция для Wi-Fi-монитора воздуха на ESP32 с датчиками SenseAir S8, AHT20 и BMP280. Версия 0.1 добавляет одно устройство с четырьмя показателями: CO₂ (ppm), температура (°C), влажность (%) и атмосферное давление (мм рт. ст.). Home Assistant получает все измерения одним запросом к `/api/data` каждые **5 секунд**. Всем четырём датчикам задан класс состояния `measurement` для истории и долгосрочной статистики HA.

## Установка

Требуется Home Assistant 2026.11 или новее.

1. Откройте **Настройки → Marketplace → Добавить по ссылке** под администратором HA.
2. Вставьте `https://github.com/Denis20241/HA_CO2_v1`, выберите тип «Интеграция», если Marketplace его запросит, и нажмите **Добавить → Установить**. При первом добавлении стороннего репозитория Marketplace может запросить подключение GitHub. Если HA предложит перезапуск, выполните его.
3. Для ручной установки скопируйте из этого репозитория папку `custom_components/senseair_s8_monitor` в `custom_components` каталога конфигурации HA, затем перезапустите HA. Это альтернативный способ установки.

## Подключение монитора

Подключите монитор к домашнему Wi-Fi через его штатную веб-страницу. В HA откройте **Настройки → Устройства и службы → Добавить интеграцию → SenseAir S8 Monitor** и введите IPv4-адрес с дисплея. Сервер HA должен иметь сетевой доступ к прибору на порту 80. При добавлении интеграция проверяет ответ монитора. Для второго прибора повторите этот шаг.

На странице устройства доступны текущие значения и история. Для графика на своей панели добавьте стандартную карточку статистики HA и выберите нужный датчик. История собирается с момента подключения, при включённом Recorder. Управление и CSV доступны в штатном веб-интерфейсе по ссылке на странице устройства.

## Если адрес или связь изменились

- Если роутер выдал прибору новый IP, откройте меню существующей записи интеграции и выберите перенастройку. Введите адрес **того же монитора**. Его сущности и накопленная история сохранятся.
- После двух неудачных опросов подряд HA помечает датчики как недоступные. После восстановления ответа значения обновляются автоматически.
- При обрыве UART между ESP32 и S8 монитор может вернуть прежний CO₂. По существующему HTTP API интеграция не может определить возраст физического измерения.
