# SenseAir S8 Monitor для Home Assistant

Локальная интеграция для монитора воздуха на ESP32 с SenseAir S8, AHT20 и BMP280. Для Home Assistant 2026.11 и новее. Один запрос к прибору каждые 5 секунд получает CO₂, температуру, влажность и давление. Вся панель работает в домашней сети с существующей прошивкой.

## Установка из ZIP

1. Распакуйте установочный ZIP. Внутри находится `custom_components/senseair_s8_monitor`.
2. Откройте каталог конфигурации **на сервере Home Assistant**. В нём лежит `configuration.yaml`. Например, на Home Assistant OS можно открыть общую папку `config` через приложение Samba share.
3. Скопируйте папку `senseair_s8_monitor` в `custom_components` этого каталога. Если `custom_components` ещё нет, создайте её. Проверьте путь `/config/custom_components/senseair_s8_monitor/manifest.json`.
4. Перезапустите Home Assistant. Для обновления установленной 0.1 скопируйте файлы поверх старых, перезапустите HA и обновите вкладку браузера. Уже добавленные приборы сохранят свои сущности, комнату и историю. Установка вручную обновляется заменой файлов. Если ранее устанавливали через Marketplace, его переустановка может заменить локальную версию.

## Установка из Marketplace

В меню **Настройки → Marketplace → Добавить по ссылке** укажите `https://github.com/Denis20241/HA_CO2_v1`. Выберите репозиторий и нажмите «Установить». При первом добавлении стороннего источника Marketplace предложит связать его с GitHub. Следуйте подсказке HA о перезапуске.

## Первое подключение

Подключите монитор к домашнему Wi-Fi. Откройте **Настройки → Устройства и службы → Добавить интеграцию → SenseAir S8 Monitor**. Введите IPv4-адрес с дисплея. Сервер HA должен видеть монитор по HTTP на порту 80. Для второго прибора повторите добавление. Если роутер сменил адрес, выберите перенастройку существующей записи и введите новый адрес того же прибора.

## Панель «Монитор воздуха»

Откройте **Монитор воздуха** в боковом меню HA и выберите прибор. На общем графике нажимайте на цветные подписи, чтобы включать и выключать линии. У каждой линии своя шкала, единицы и диапазоны видны под графиком. Ниже расположены четыре отдельных графика с минимумом, средним и максимумом. Наведите курсор, коснитесь графика или используйте клавиши со стрелками.

Переключатель **Час · Сутки · Неделя · Год** действует на все графики. Час показывает изменения показаний, сутки используют пятиминутную статистику Recorder, неделя — часовую, год — дневные сводки из почасовой истории. При первом подключении история начинает накапливаться. После обновления доступна прежняя история этих же сущностей. Новые замеры доступны сразу на часовом графике. Панель всегда показывает давление в **мм рт. ст.** Для штатной сущности HA это рекомендуемая единица. Явный выбор пользователя сохраняется.

Суточный график CO₂ показывает время строго выше 1200 ppm и общую длительность наблюдения. Учёт начинается при запуске версии 0.2. Пропуски опросов и перезапуски исключаются. После двух неудачных опросов HA отмечает прибор недоступным и продолжает проверять связь. При потере UART штатная прошивка может вернуть последнее значение S8. HTTP API не передаёт возраст физического измерения.

Внизу панели доступны диагностика, часовые максимумы из памяти прибора и исходный CSV. Журнал прибора очищается при его перезапуске. Администратору доступны переключение ABC, калибровка, поправки, смена Wi-Fi и заводской сброс с подтверждением. После смены сети дождитесь нового успешного ответа. При изменении IP выполните перенастройку существующей записи.
